# KIAN CASHIER — نظام كيان كاشير ونقاط البيع المتكامل

نظام كاشير ونقاط بيع متطور يعمل بدون اتصال بالإنترنت (Offline-First PWA) مع إدارة متكاملة للمخزون، المبيعات، الفواتير، ديون العملاء، الأرباح، وحسابات الذهب والعملات.

---

## 🚀 أولاً: تشغيل المشروع محلياً على جهازك (Local Development)

### المتطلبات الأساسية:
- تثبيت [Node.js](https://nodejs.org) (الإصدار 18 أو 20 أو أحدث).

### خطوات التشغيل:
1. قم بفك ضغط المشروع أو استنساخه من GitHub:
   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   cd YOUR_REPO_NAME
   ```

2. قم بتثبيت الحزم والمكتبات:
   ```bash
   npm install
   ```

3. شغّل خادم التطوير (Full-Stack Dev Server):
   ```bash
   npm run dev
   ```

4. افتح المتصفح على الرابط:
   ```
   http://localhost:3000
   ```

## 🌐 ثانياً: تشغيل ونشر الموقع مباشرة على الإنترنت عبر GitHub Pages مجاناً

المشروع يحتوي بالفعل على مسار أتمتة جاهز داخل `.github/workflows/static.yml` لبناء الموقع ونشره تلقائياً.

### خطوات التفعيل في GitHub (خطوة بخطوة):

1. **ارفع الكود إلى GitHub**:
   - إذا كنت تستخدم AI Studio: اضغط على القائمة العلوية ثم اختر **Export to GitHub**، أو حمّل المشروع وارفع ملفاته إلى مستودعك الجديد على GitHub.
   
2. **تفعيل البناء التلقائي عبر GitHub Actions (الخطوة الأهم)**:
   - افتح مستودعك على موقع **GitHub**.
   - توجّه إلى التبويب: **Settings** (الإعدادات).
   - من القائمة الجانبية اليسرى، اضغط على: **Pages**.
   - تحت قسم **Build and deployment**:
     - في خانة **Source**، غيّر الاختيار من *(Deploy from a branch)* إلى: **`GitHub Actions`**.
   - احفظ التغيير.

3. **اكتمال النشر والحصول على الرابط**:
   - بمجرد اختيار **GitHub Actions**، سيبدأ البناء تلقائياً (يمكنك متابعته من تبويب **Actions** في المستودع).
   - بعد دقيقة واحدة، ستجد رابط موقعك متاحاً ويعمل مباشرة تحت قسم **Pages**، بصيغة:
     ```
     https://<YOUR_USERNAME>.github.io/<YOUR_REPO_NAME>/
     ```

## 🛠️ ثالثاً: إصلاح الأخطاء الشائعة وحلولها (Troubleshooting)

### 1. خطأ 404 (الصفحة البيضاء أو عدم تحميل ملفات CSS و JS على GitHub Pages)
- **السبب**: عند تشغيل الموقع على نطاق فرعي لمستودع GitHub (مثل `/repo-name/`)، تفشل المسارات المطلقة مثل `/assets/`.
- **الحل الذي تم تطبيقه**: تم ضبط `base: './'` داخل `vite.config.ts`، وتحويل جميع مسارات `index.html` و `manifest.json` و `sw.js` لتكون مسارات نسبية `./`، وبالتالي سيعمل الموقع بشكل سليم بنسبة 100% سواء على النطاق الرئيسي أو أي مجلد فرعي.

### 2. فشل الـ Action مع خطأ في الصلاحيات (Permission denied)
- **الحل**: 
  1. ادخل إلى **Settings** في مستودعك.
  2. اضغط على **Actions** ثم **General**.
  3. انزل إلى قسم **Workflow permissions**.
  4. اختر **Read and write permissions** ثم اضغط **Save**.

### 3. هل يعمل التطبيق بدون إنترنت (PWA)؟
- **نعم**: التطبيق مصمم بالكامل بنمط **Offline-First**. بمجرد فتحه للمرة الأولى، يقوم الـ Service Worker بتخزين جميع ملفات الواجهة والخطوط، وتُحفظ جميع المبيعات والمنتجات في التخزين المحلي للمتصفح (IndexedDB / LocalStorage) لضمان استمرار الكاشير في العمل حتى عند انقطاع الإنترنت.
