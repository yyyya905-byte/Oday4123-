# خطة العمل: رفع طبقة النوافذ المنبثقة إلى أعلى مستوى (z-[9999]) وخلفية معتمة وحركة انتقال CSS سلسة

تم إنجاز ترقية نظام النوافذ المنبثقة (Modals & Dialogs) في التطبيق بأكمله بنجاح، وخصوصاً شاشة الكاشير (POS) ونوافذ اختيار التجار والعملاء، لتظهر فوق جميع عناصر الواجهة دون أي تداخل مع الرأس أو السلة أو القوائم العائمة، مع حركة دخول انسيابية (Fade-in + Subtle Slide from Top to Center).

---

## 1. التحديثات المكتملة

### أ. نافذة اختيار تاجر الجملة (`WholesalePOSHeader.tsx`)
- **الترقية إلى نافذة علوية مستقلة**: تحويل القائمة المنسدلة من نمط `absolute` محدود بالحاوية إلى نافذة حوارية علوية كاملة في الطبقة `fixed inset-0 z-[9999] bg-black/75 backdrop-blur-md`.
- **حركة الانتقال CSS السلسة**: إضافة فئة الحركة `.modal-enter-slide-down` للبطاقة وفئة `.modal-backdrop-animate` للخلفية المعتمة لإضفاء تجربة فتح فائقة النعومة.
- **دعم إغلاق النافذة بزر Escape والنقر الخارجي**: إضافة مستمع للوحة المفاتيح للتعامل مع مفتاح `Esc` وزر إغلاق بمساحة لمس مريحة.
- **مؤثرات صوتية وملموسة**: تفعيل النقر الزجاجي عند الفتح والصوت التأكيدي عند اختيار التاجر.
- **عرض تفاصيل سقف الائتمان والذمة**: تبيان رصيد الذمة وسقف المديونية لكل تاجر مع شريط بحث فوري.

### ب. نافذة اختيار عميل الولاء بالتجزئة (`RetailPOSHeader.tsx`)
- ترقيتها إلى نافذة كاملة علوية بطبقة `z-[9999]` مع حركة الدخول الانسيابية والخلفية المعتمة.

### ج. محرك النوافذ المنبثقة العام (`DraggableModalWrapper.tsx`)
- تطبيق حركة الانتقال `.modal-enter-slide-down` وتعتيم الخلفية `.modal-backdrop-animate` لجميع النوافذ المنبثقة التابعة للمغلف العام القابل للسحب.
- رفع الطبقة الافتراضية إلى `z-[9999]` مع دعم خاصية `zIndexClass="z-[10000]"` للنوافذ المتفرعة مثل الطباعة الحرارية وتخصيص الإيصال.

### د. حركات CSS في `src/index.css`
- تعريف الإطارات المفتاحية `@keyframes modalSlideDownFade` مع ترجمة رقيقة من `-24px` مع `scale(0.96)` إلى `0` مع `scale(1)`.
- تعريف `@keyframes backdropFadeIn` لظهور تدريجي ناعم للخلفية المعتمة.
- تضمين استجابة مخصصة لخاصية تقليل الحركة `prefers-reduced-motion` لحفظ راحة وسلاسة الاستخدام.
